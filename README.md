# My Portfolio Website 🌐

A personal portfolio showcasing my skills, projects, and experience. Built with modern web technologies to create a responsive and visually appealing experience.

## 🔗 Live Demo
[Check it out here](https://mradul-patle.onrender.com/)

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript, React.js
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion / Animate.css
- **Deployment:** Render
- **Tools:** Git, VSCode

## 💻 Features
- Responsive layout for mobile, tablet, and desktop
- Projects showcase with live demo links & GitHub repositories
- Skills section with programming languages and frameworks
- Contact form for direct messages
- Smooth animations and transitions
